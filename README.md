# Week 4 – Security Policy Review

## About the Task

This repository contains my Week 4 internship task on **Security Policy Review, Evaluation, and Improvement Recommendations**.

The objective of this task is to review a generic organizational security policy, identify its strengths and weaknesses, compare it with recognized cybersecurity standards, and provide practical recommendations for improvement.

## Topics Covered

- Access Control and Authentication
- Password and Identity Management
- Data Protection
- Incident Response
- Backup and Recovery
- Remote Work Security
- Security Awareness
- Third-Party Security
- Vulnerability and Patch Management
- Security Monitoring and Logging
- Security Governance

## Standards Referenced

- NIST Cybersecurity Framework (CSF) 2.0
- ISO/IEC 27001:2022
- NIST SP 800-53 Rev. 5

## Deliverable

The complete security policy review report is available in:

**`task4yuva.docx`**

The report includes security analysis, comparison tables, cybersecurity lifecycle diagrams, actionable recommendations, an implementation roadmap, and security metrics.

## Key Outcome

This task helped me understand how security policies are evaluated against industry practices and how organizations can improve their overall cybersecurity posture through continuous risk management and security improvement.
